# Анализ лояльности пользователей Яндекс Афиши

## Описание проекта

Проект посвящён анализу покупательского поведения пользователей Яндекс Афиши. Цель — изучить повторные покупки, выявить особенности разных групп клиентов и подготовить рекомендации по повышению лояльности.

## Структура проекта

- `main.py` — основной файл запуска.
- `src/processing.py` — класс DataProcessor для обработки и анализа данных.
- `src/download_data.py` — загрузка данных из PostgreSQL.
- `data/` — исходные CSV-файлы.
- `.env` — параметры подключения к базе данных.
- `.env.example` — шаблон переменных окружения.
- `requirements.txt` — зависимости проекта.

## Используемые технологии

Python, Pandas, NumPy, Matplotlib, Phi-k, SQLAlchemy, PostgreSQL, python-dotenv.

## Подготовка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/vikaonline2022/mle-analiz-loyalnosti-polzovatelej.git
cd mle-analiz-loyalnosti-polzovatelej
```

### 2. Создание виртуального окружения

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка библиотек

```bash
pip install -r requirements.txt
```

### 4. Настройка подключения к базе данных

Создайте файл `.env` в корне проекта на основе `.env.example` и укажите свои параметры подключения:

- DB_USER
- DB_PWD
- DB_HOST
- DB_PORT
- DB_NAME

Не публикуйте `.env` в GitHub.

### 5. Подготовка данных

Для загрузки заказов из PostgreSQL выполните:

```bash
python3 src/download_data.py
```

Скрипт сохранит заказы в `data/orders.csv`.

Также необходимо поместить в папку `data/` файл `final_tickets_tenge_df.csv` с курсами валют.

### 6. Запуск анализа

После подготовки обоих CSV-файлов выполните:

```bash
python3 main.py
```

## Результаты анализа

После очистки данных получено 21 622 пользовательских профиля.

Основные показатели:

- Доля повторных покупателей — 61,34%.
- Средняя выручка на пользователя — 545,11 руб.
- Медианная выручка на пользователя — 464,12 руб.
- Среднее количество заказов — 6,50.

Доля повторных покупателей по типу первого мероприятия:

- Выставки — 64,16%.
- Театр — 63,39%.
- Концерты — 61,83%.
- Спортивные мероприятия — 55,79%.

В активных регионах доля повторных покупателей составила 62,55%, в менее активных — 58,24%.

Медианная выручка повторных покупателей составила 496,13 руб., пользователей с одним заказом — 378,98 руб. Средняя выручка в этих группах практически одинакова.

Корреляционный анализ Phi-k показал заметную связь региона с типом первого мероприятия (0,51), а также группы по количеству заказов со средним интервалом между покупками (0,43).

## Бизнес-рекомендации

1. Развивать персональные рекомендации на основе типа первого приобретённого билета или мероприятия.
2. Дополнительно исследовать причины более низкой доли повторных покупок в сегменте спортивных мероприятий.
3. Изучить практики регионов с высокой долей повторных покупателей и проверить возможность их применения в других регионах.
4. Стимулировать вторую покупку с помощью персональных предложений и напоминаний после первого заказа.
5. Разрабатывать программы лояльности для активных покупателей.
6. Проверять эффективность маркетинговых мероприятий с помощью A/B-тестов.

Результаты корреляционного анализа показывают взаимосвязи между признаками, но не доказывают причинно-следственные зависимости.
